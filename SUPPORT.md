# Support

For product support, open an issue in this repository.

## Include These Details

- Page URL
- Tool area: formatter, validator, converter, diff, tree editor, schema validator, minifier, or TOON converter
- Input sample if safe to share
- Expected result
- Actual result
- Browser, device, and locale

Do not post private data, production secrets, API keys, customer records, or sensitive JSON payloads in public issues.
